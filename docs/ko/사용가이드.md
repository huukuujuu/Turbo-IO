# Turbo IO 한국어판 · 외부 AI와 서비스 연결

현재 설치 대상은 Turbo IO **V1 독립 iPhone 앱**입니다. 원본 프로젝트의 V2 공식 앱 확장이나 커스텀 펌웨어 안내와 기능이 다릅니다. 기본 안경 연결은 iPhone 16 / Strix OS 1.0.6.14에서 확인했습니다. 외부 서비스 호출은 키를 설정한 뒤 각각 검증해야 합니다.

## 어떤 연결이 필요한가요?

| 원하는 기능 | 필요한 연결 | 설정 위치 |
|---|---|---|
| 안경으로 질문하고 AI 답변 받기 | Alibaba Cloud ASR + DeepSeek | 대화 → 음성 AI 연결 설정 |
| 저장한 녹음을 텍스트로 바꾸기 | Alibaba Cloud ASR | 같은 음성 AI 연결 설정에서 키 저장, 이후 녹음 상세에서 전사 시작 |
| PC의 Codex에 직접 텍스트 작업 보내기 | PC의 Codex 브리지 | 도구 → Codex 콘솔 |
| 음성으로 Codex에 작업 보내기 | ASR + DeepSeek + Codex 브리지 | 음성 AI 설정 + Codex 도구 호출 허용 |
| 할 일·책·원고 편집, 로컬 오디오 보관 | 외부 AI 키 불필요 | 해당 도구 화면 |
| 안경에서 날씨 보기 | QWeather 또는 Weatherstack | 날씨 및 기기 설정 |
| 다른 GPT/Claude 등 임의 모델 주소 저장 | 현재는 초안 저장만 지원 | 다른 모델 설정 초안 |
| AI 답변 읽어주기(TTS) | 현재 V1 경로에 연결되지 않음 | 저장 전용 TTS 옵션은 실제 실행에 영향 없음 |

## 음성 AI 대화

흐름은 **안경 마이크 → ASR(음성을 글로) → DeepSeek(답변 생성) → 안경의 텍스트 표시**입니다.

ASR는 음성 인식 서비스입니다. 본인의 ASR 호스트명과 Alibaba Cloud API 키가 필요합니다. 이 코드가 허용하는 호스트는 `*.aliyuncs.com`이며 프로토콜·경로·포트를 제외한 호스트명만 입력합니다. 실행 모델은 `qwen-audio-3.0-asr-flash-streaming`이고 DashScope WebSocket 스트리밍 프로토콜을 사용합니다. 사용하는 서비스·지역에서 해당 모델과 프로토콜을 제공하는지 확인해야 합니다. 임의의 음성 인식 서비스 키로 대체할 수는 없습니다.

DeepSeek는 인식된 질문에 답하는 모델 서비스입니다. 별도 DeepSeek API 키가 필요합니다. 현재 코드는 `https://api.deepseek.com/chat/completions` 및 `deepseek-v4-flash`로 고정되어 있습니다. 현재 모델 실행기는 ‘다른 모델 설정 초안’에 저장한 주소나 이름을 읽지 않습니다.

설정을 저장한 것과 서비스 연결 성공은 다릅니다. 키 저장 후 음성 대기를 켜고, 안경에서 직접 호출하여 짧은 질문의 인식과 응답을 각각 확인해야 합니다. 오디오는 ASR로, 인식 텍스트와 대화 문맥은 DeepSeek로 전달되며 두 서비스에서 사용량이 발생할 수 있습니다. 기본 응답 언어는 한국어로 수정했지만 실제 한국어 음성 인식·안경 글꼴 표시는 서비스와 기기에서 확인해야 합니다.

‘클라우드 AI 대화 사용’을 끄면 로컬 말소리 감지 및 무작위 문자 테스트를 선택합니다. 이 테스트는 말을 알아듣거나 질문에 답하는 기능이 아닙니다.

## 녹음과 전사

안경 녹음을 받아 기기에 저장하는 기능 자체에는 AI 키가 필요하지 않습니다. 저장된 오디오에서 ‘ASR 전사 시작’을 눌러 확인하면 선택한 오디오가 ASR로 전송됩니다. 전사 결과는 새 Markdown 수정본으로 보관하며 원본 오디오와 이전 수정본을 유지합니다.

전사 실행 자체는 DeepSeek를 사용하지 않으며 자동 요약도 하지 않습니다. 다만 현재 키 저장 UI는 음성 대화용으로 만들어져 ASR와 DeepSeek 키를 함께 요구합니다. ASR만 독립적으로 저장하는 화면은 아직 없습니다. 수동 전사는 최대 10분 오디오 / 디코딩된 PCM 32 MiB로 제한됩니다.

## Codex 브리지

Codex 콘솔은 PC에 작업을 보내고 결과를 확인하는 별도 기능입니다. PC에서 프로젝트의 `codex-bridge`를 실행하고, 휴대폰에서 접근할 수 있는 HTTPS 주소와 전용 토큰을 앱에 넣어야 합니다. PC의 Codex 로그인도 필요합니다.

이 전용 토큰은 ASR 키나 DeepSeek 키와 다릅니다. PC 브리지와 통신할 권한을 확인하는 값입니다. 직접 텍스트를 입력해서 보내는 작업은 ASR나 DeepSeek 없이 사용할 수 있습니다. 음성으로 명령하려면 ASR와 DeepSeek 음성 대화를 구성하고, Codex 콘솔에서 ‘DeepSeek의 Codex 도구 호출 허용’을 켜야 합니다.

현재 모델 도구는 작업 시작/계속(`codex_message`), 상태 확인(`codex_status`), 작업 중지(`codex_stop`)입니다. 일반 할 일·날씨·녹음이 전부 모델 도구로 등록된 것은 아닙니다. 권한 승인과 질문 답변은 휴대폰에서 직접 확인하며 AI가 자동으로 승인하지 않습니다.

## 다른 모델 설정 초안과 TTS

‘다른 모델 설정 초안’은 HTTPS 주소, 모델 이름, API 키를 저장하는 화면입니다. 현재 V1의 실제 음성 대화 실행기에는 연결되지 않았습니다. 이곳에 다른 서비스 주소를 넣어도 음성 AI가 그 서비스로 바뀌지 않습니다.

로컬 Sherpa, 사용자 클라우드, 시스템 음성, 사용자 TTS도 이 화면에서는 계획용 설정입니다. 현재 설치한 V1 음성 경로에는 답변 읽어주기가 연결되어 있지 않습니다. 프로젝트 V2 설명에 있는 임의 모델·TTS 지원을 이 앱의 완성된 기능으로 보면 안 됩니다.

## 날씨와 로컬 기능

QWeather는 전용 호스트, API 키, 지역 좌표로 날씨를 조회합니다. 자동 대시보드 날씨는 이 경로를 사용합니다. 이전 Weatherstack 화면은 별도의 키와 도시를 사용하며 수동 조회를 제공합니다. 두 서비스의 키는 서로 재사용하지 않습니다. 입력한 좌표나 도시를 해당 서비스로 보내고 휴대폰 GPS나 녹음·대화를 전송하지 않습니다.

할 일 편집, TXT/EPUB 읽기, 프롬프터 원고, 오디오 보관, 사용자 알림 테스트는 외부 AI 키 없이 사용할 수 있습니다. 안경 표시에는 연결과 각 기능의 전송 확인이 필요합니다. 시스템 알림 공유 권한은 iPhone 설정에서 별도로 허용합니다.

‘일상 기록’은 현재 30초 오디오 프로토콜 테스트입니다. AI 요약·일정 추출·상시 기록까지 완성된 서비스가 아닙니다.

## 이번 검수 범위

탭과 버튼뿐 아니라 상태·오류 안내, 녹음 수신·복구·전사, 할 일 동기화, 알림, 날씨, Codex 도구 설명, 내보낸 Markdown 안내, SDK 진단 표시와 기본 AI 응답 지시문까지 확인했습니다. 저장된 설정의 내부 선택값과 기기 연결 식별자는 유지합니다. 사용자가 입력한 제목, 책 본문, 기존 녹음의 전사 원문, 외부 서비스가 반환한 내용은 번역 대상이 아닙니다.

앱의 **도구 → 외부 AI·서비스 연결 안내**에서도 기능별 설명을 읽을 수 있습니다.
