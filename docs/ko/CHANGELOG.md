# 한국어 iPhone 빌드 변경 이력

기준 원본: Turbo1123/Turbo-IO, 커밋 `28a0fef0a42773f38222fcd0db2e0f2852ed4257`.
경로: V1 독립 SDK iPhone 앱. 공식 앱 확장(V2) 및 펌웨어 변경은 포함하지 않습니다.

## 2026-11-18 · 0.2.0 (6)

- 음성 대화와 저장 녹음 전사 요청에 `language_hints: ["ko", "en"]`을 추가했습니다. 기존에는 언어 힌트가 없어 모델이 자동 판별했습니다.
- 한국어·영어 위주의 사용에서 중국어 등 다른 언어로 오인식하는 경우를 줄이기 위한 설정입니다. 힌트는 강제 언어 필터가 아니며 실제 정확도 개선은 같은 음성으로 비교해야 합니다.
- 대화 화면에 적용된 언어 힌트와 한계를 표시합니다. 기존 키·모델·오디오 형식은 유지합니다.
- 근거: [Alibaba Qwen Audio 스트리밍 ASR 언어 힌트](https://www.alibabacloud.com/help/en/model-studio/qwen-audio-asr-streaming-java-sdk).
- 검증: 기기 빌드·코드 서명·iPhone 설치 및 한국어 정적 검사 통과. 실제 사용자 음성의 오인식 감소율은 아직 측정하지 않았습니다.

## 2026-11-18 · 0.2.0 (5)

- 탭, 버튼, 안내, 동적 상태·오류, 녹음·전사, 할 일, 날씨, 알림, Codex 화면 및 Markdown 내보내기 문구를 한국어로 변경했습니다.
- 내부 선택 태그와 기존 저장값, 접근성 식별자를 유지했습니다. 사용자 입력과 기존 기록은 번역하지 않습니다.
- SDK 진단을 UI 경계에서 한국어로 요약하고, Bluetooth 페어링 정보 불일치(CBError 14)를 안내합니다.
- 외부 서비스별 데이터 흐름과 실제 실행 조건을 설명하는 안내 화면을 추가했습니다. 범용 모델 설정은 저장 전용 초안임을 표시합니다.
- DeepSeek 기본 답변 언어를 한국어로 설정했습니다.
- DeepSeek HTTP 오류 번호와 네트워크 오류 코드를 표시하고, 고정 문장 연결 테스트 및 같은 키의 API 잔액 조회를 추가했습니다.
- 한국어 번역표, 재적용 스크립트, 정적 검사와 UI 검수 테스트를 보관합니다.

### 검증

- 전체 한국어 검수 시 단위 테스트 217개 및 UI 순회 테스트 1개 통과, 화면 6개 육안 확인.
- 최종 진단 변경 후 iPhone 기기용 빌드, 서명 및 설치 확인. 실제 기기에서 HTTP 402 처리와 API 잔액 조회를 확인했습니다.
- 한국어 정적 검사: 미번역 UI 0줄, 유지한 내부 선택·저장값 14줄.
- `git diff --check` 통과. Codex 브리지 테스트 15개 통과, 로컬 인증된 상태 조회 및 미인증 401 차단 확인.

### 기능 범위

- 실제 음성 대화는 Alibaba ASR → DeepSeek → 텍스트 표시 조합입니다. 다른 모델 설정 초안은 이 실행 경로를 바꾸지 않습니다.
- 공식 안경 메뉴의 라이브 캡션·실시간 번역과 답변 TTS는 이 V1 빌드에 연결되지 않았습니다.
- 정상 유료 모델 응답, 자막, 모든 안경 화면의 동작을 검증했다는 의미는 아닙니다.
- Codex는 별도 PC 브리지가 필요합니다. 원격 Linux 배포는 안내만 제공했으며 원격 기기에서 검증하지 않았습니다.

### 재현 및 이력 관리

`python3 localizations/audit_ko.py`로 한국어 UI를 검사합니다. 기기 빌드는
`apps/RayNeoCompanion/project-device.yml`을 XcodeGen으로 생성한 뒤
`RayNeoCompanionDevice` 스킴과 본인의 Apple 개발 팀으로 빌드합니다.
실기기 테스트에는 본인의 안경과 서비스 자격 증명이 필요합니다.

변경은 `ko/ios-personal` 브랜치에서 커밋하고 개인 fork의 `origin`에 푸시합니다.
원본 업데이트는 `git fetch upstream`으로 가져온 뒤 검토하여 병합합니다.
로그·빌드 결과·SwiftPM 사용자 설정·API 키·서명 인증서는 커밋하지 않습니다.
